# マネタイズ設計 — 広告モデルはなぜ個人開発に閉ざされているか

前2作（[キラーコンテンツ分析](./killer-content-analysis.md) / [新規企画5案](./new-mechanics-from-scratch.md)）の続き。
TikTok と BeReal が実際にどう稼いでいるかを確認し、そこから**個人開発者が取れる型**を絞り込む。

数値は出典に書かれている範囲のみ記載。第三者推計や情報源によって食い違う箇所は、その旨を明記した。

---

## 1. TikTok — 広告75%の会社

2025年の売上は約331億ドル。内訳はおおむね次の3本。

| 収益源 | 仕組み | 規模 |
|---|---|---|
| **広告** | フィード内広告。売上の約75% | 2026年予測 約439.6億ドル |
| **TikTok Shop** | 動画に商品リンク。販売手数料 5〜8% | GMV 2024年332億ドル → 2025年660億ドル → 2026年予測1,122億ドル |
| **ライブギフト / コイン** | 投げ銭。**プラットフォームが約50%を取る**（200ダイヤ = 1ドル） | — |

構造として重要なのは、**3本ともユーザー数に比例する**という点。
広告は表示回数、Shop は流通額、ギフトは投げる人の数に比例する。
つまり TikTok のモデルは、**規模がすべての前提**になっている。

---

## 2. BeReal — 「バズっても稼げない」ことの実証

BeReal は最初の3年間、収益化を一切していない。その後の経緯はこうなる。

1. **2024年6月**、Voodoo（仏のアプリ／ゲームパブリッシャー）が約5億ユーロで買収。
   ただし**現金は1.66億ドルのみで、残り3.34億ドルは将来の業績に紐づく成功報酬**
2. **2024年7月**、アプリ内広告を導入
3. **2025年4月**、米国向けの広告プラットフォームを開設。
   フィード内広告、1日まるごとのブランドジャック、
   ブランドが一般ユーザーのように投稿する「RealBrands」などを展開
4. Nike・Netflix・Amazon を含む**200社以上**が出稿

### 稼げているのか

**推計は情報源によって大きく食い違う。**

- 2026年の年間売上は **500万〜1,000万ドル** という推計
- 一方、広告導入後の最初の1年で **約3,200万ドル** という推計もある

前者と後者で3倍以上の開きがあるため、正確な数字は外部からは確定できない。
だが、**どちらの数字を取っても結論は変わらない。**

> BeReal は月間アクティブ約4,000万人を抱えて、年間で数百万〜数千万ドル。
> **ユーザー1人あたり、年間で1ドルにも満たない。**

これが広告モデルの実態である。バズったから稼げるのではない。

---

## 3. 対照実験 — Locket

同じ「親密な少人数」型でも、Locket はサブスクリプションを選んだ。

- 2024年に **Locket Gold** を開始（広告除去・ウィジェットのカスタマイズ・エンゲージメント表示）
- **課金ユーザー10万人以上**
- 直近の月間売上は **約30万ドル**（2026年3月時点の第三者推計）

年換算で約360万ドル。BeReal より桁違いに小さいユーザー数で、
**BeReal の推計レンジの下限に匹敵する売上**を出している。

| | BeReal | Locket |
|---|---|---|
| モデル | 広告 | サブスクリプション |
| ユーザー規模 | MAU 約4,000万 | 累計8,000万DL・課金10万人超 |
| 年間売上（推計） | 500万〜3,200万ドル | 約360万ドル |
| 必要なもの | 広告営業組織・出稿社200社・配信基盤 | **App Store の課金だけ** |

**個人開発者に開かれているのは、明確に右側だけ。**

---

## 4. ただし、サブスクの現実は厳しい

期待値を正しく持っておく必要がある。RevenueCat の2026年調査より。

| 指標 | 数値 |
|---|---|
| ローンチ1年後の**中央値** | 月商 **72ドル** |
| 上位25% | 月商 429ドル超 |
| 上位10% | 月商 2,574ドル超 |
| 新規アプリのうち、累計1,000ドルに到達しない割合 | **57.7%** |
| 2年以内に MRR 1万ドルに到達する割合 | **4.6%**（MRR 1,000ドルなら17.3%） |
| **上位10%が全サブスク売上に占める割合** | **94.5%** |

さらに、2020年以前にローンチしたアプリが今も全売上の69%を占めており、
新規サブスクアプリの月間ローンチ数は2022年1月の約2,000本から2026年1月には14,700本超に増えている。

### この数字の読み方

悲観する数字ではなく、**目標を正しく置くための数字**として読む。

上位10%の閾値は月商2,574ドル。仮に月額500円（約3.3ドル）で課金するなら、
**課金者およそ800人で上位10%に入る**。
コンバージョン率4%（後述の適正レンジ）なら、必要なのは MAU 2万人程度。

> 目標は「TikTok になること」ではない。
> **課金者800人**である。これは個人開発の射程にある。

## 5. 本題 — 課金モデルは6軸のどこで決まるか

ここが今回の結論。**マネタイズは後から考えるものではなく、軸4と軸6で既に決まっている。**

### 軸4（社会的単位）が、取れるモデルを決める

| 軸4 | 取れるモデル | 個人開発で可能か |
|---|---|---|
| 他人（インタレストグラフ） | 広告・手数料・投げ銭 | ✗ 規模が前提。TikTok になるまで成立しない |
| **親密な少人数（N=2）** | **サブスクリプション** | ✓ Locket が実証済み |
| 自分自身 | 買い切り課金・サブスク | △ 継続の社会的圧力がないぶん弱い |

N=2 型がサブスクに強いのは、**関係そのものが商品だから**。
人は自分のためのツールは解約するが、相手との関係が乗っているものは解約しづらい。

### 軸6（反復耐性）が、課金が続くかを決める

**サブスクリプションは、繰り返し使うものにしか課金できない。**

1回で驚きを使い切るアプリ（＝ latent の現状）に月額を課すことはできない。
取れるのは買い切り課金だけで、それは1人あたり数百円で打ち止めになる。

逆に言えば、前作で「蓄積型しか使えない」と結論したのは、
**そのまま「蓄積型しかサブスクにできない」という意味でもあった。**

> **課金モデルは軸4が決め、課金が続くかは軸6が決める。**
> 6軸を通したアイデアは、マネタイズの型も同時に決まっている。

---

## 6. 蓄積型 × サブスクは、構造的に相性が完璧

これが個人開発における最も重要なレバレッジ。

蓄積型のアプリでは、**アーカイブが毎日ぶんだけ価値を増していく**。
1ヶ月使ったユーザーにとって解約コストは小さいが、
1年使ったユーザーにとっては「1年分の記録を失う」ことになる。

> **蓄積そのものが解約防止装置になる。**
> チャーンが時間とともに下がる、数少ないアプリ類型。

サブスクの最大の敵は解約であり、蓄積型はそれを設計で解いている。

---

## 7. 企画A「せーの」への適用

前作で推奨した2人組アプリに、この結論を当てはめる。

### 売るもの

Locket Gold が「広告除去・カスタマイズ・エンゲージメント表示」を売ったのと同じ発想で、
**中核の制約に触らずに、関係を深める側**を売る。

| 売るもの | なぜ効くか |
|---|---|
| **過去の全履歴** — 無料は直近7日だけ | 蓄積そのものを課金対象にする。時間が経つほど解約しづらくなる |
| **年次の書き出し** — 1年分の2枚組を1本にまとめる | Wrapped 型の出力。軸3（観測可能性）にも同時に効く |
| **ペアを増やす** — 無料は1ペア、有料で複数 | 恋人＋親友＋実家。ARPU とバイラルの両方に効く |
| **2人だけの自作お題** | 関係の固有性を売る。中核体験を壊さない |

### 絶対に売ってはいけないもの

**撮り直し・フィルタ・お題のスキップ・時間制限の解除。**

これらは軸2（投稿コストをゼロにする制約）そのものを壊す。
BeReal は制約が緩んだ結果「無加工を演じる場」になって失速したが、
**課金でそれをやると、同じ失敗を自分の手で、しかも有料で再現することになる。**

> 制約は商品ではない。制約はアプリの土台であって、崩したら建物が落ちる。

### 価格設計 — freemium が強制される

データ上は**ハードペイウォールのほうが圧倒的に有利**である。

| | 30〜35日の有料転換率 | インストールあたり売上（60日） |
|---|---|---|
| ハードペイウォール | 中央値 **10.7%** | **3.09ドル** |
| フリーミアム | 中央値 **2.1%** | 0.38ドル |

**だが「せーの」ではハードペイウォールは選べない。**

このアプリは招待でしか成立しない（軸5）。
招待された側が起動していきなり課金画面に当たったら、そこで招待が死ぬ。
**バイラル係数1.0という最大の武器と、ハードペイウォールは両立しない。**

したがってフリーミアム一択。よく運用されたフリーミアムの30日転換率は **2〜8%** が相場なので、
その中央あたり4%を前提に置くのが現実的な計画になる。

これは軸5を武器にしたことの**コスト**であり、
「6軸で強いものはマネタイズでも強い」とは限らない、という正直な注記でもある。

---

## 8. まとめ

1. **TikTok のモデル（広告・手数料・投げ銭）は規模が前提であり、個人開発には閉じている**
2. **BeReal は MAU 4,000万でユーザー1人あたり年間1ドル未満。バズと収益は別物**
3. **Locket は桁違いに小さい規模でサブスクにより同等の売上を出している。取れるのはこちら**
4. **サブスクの中央値は月商72ドル。だが上位10%の閾値は課金者800人程度で、射程内**
5. **課金モデルは軸4が、継続は軸6が決める。6軸を通したアイデアはマネタイズの型も決まっている**
6. **蓄積型 × サブスクは、蓄積そのものが解約防止になるため構造的に強い**
7. **制約だけは絶対に売らない。売った瞬間に BeReal の失敗を有料で再現することになる**
